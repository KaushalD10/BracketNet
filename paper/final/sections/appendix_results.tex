\section{Reproducibility}\label{app:repro}
The anonymized supplementary code contains everything needed to reproduce the paper:
\begin{itemize}
\item the data generator, the model and training code;
\item the pre-registered selection rules and the generated frozen protocol;
\item per-run JSON files for every development, fresh-seed and ablation run, and the fresh-seed checkpoints;
\item the analysis script that produces every table and every number in the text (as \LaTeX{} macros);
\item the figure scripts and the mathematical unit tests.
\end{itemize}
Repeated runs are bit-identical on the same machine. All runs are CPU-only and take 31--106\,s each for \NSteps{} updates (four runs in parallel).
