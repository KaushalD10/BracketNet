# Final mathematical audit

Every result in the final manuscript is restated with exact hypotheses, re-derived independently of the earlier
draft, and checked for counterexamples. **Proof** means a written derivation (below). **Computational check** means a
numerical test; tests are evidence, not proofs. Where possible the tests are *independent* of the derivation: they use
different invariants (Pfaffian vs. participation ratio), optimization that does not know the classification, or
explicit constructions on the actual data.

No human mathematician has reviewed these proofs. They were produced with AI assistance and must be checked by the
authors before submission.

Notation:
* A_1..A_K ∈ so(d), and B = [vec A_1, …, vec A_K] ∈ R^{d²×K}.
* G = BᵀB, and 𝔞 = span A.
* P₀ is the Frobenius-orthogonal projector onto 𝔞, and N = I − P₀.
* L(A; ε) = K⁻² Σ_{ij} ‖(I − P_ε) vec[A_i, A_j]‖², with P_ε = B(G + εI)⁻¹Bᵀ.

## R1. Transformation law of the closure loss (unchanged; verified)
**Hypotheses.** B has full column rank and M ∈ GL(K).

**Statement.** L(BM; 0) = K⁻² ‖R(M⊗M)‖_F², where R = N·[vec[A_i, A_j]]_(ij), columns ordered i-major. Hence
σ_min(M)⁴ L ≤ L(BM; 0) ≤ σ_max(M)⁴ L. Also P_ε(BM) = B(G + ε M⁻ᵀM⁻¹)⁻¹Bᵀ.

**Derivation.**
1. [A'_i, A'_j] = Σ_{kl} M_ki M_lj [A_k, A_l], so the commutator matrix becomes C(M⊗M), with
   (M⊗M)_{(kl),(ij)} = M_ki M_lj.
2. P₀ depends only on the column space, so R ↦ R(M⊗M).
3. The singular values of M⊗M are σ_iσ_j, which gives the bounds.
4. For ε > 0, BM(MᵀGM + εI)⁻¹MᵀBᵀ = B[M⁻ᵀ(MᵀGM + εI)M⁻¹]⁻¹Bᵀ.

**Consequences.** Exact invariance holds only for orthogonal M. The zero set is GL(K)-invariant, and P_ε depends
on more than the span.

**Checks:** T1, T2 (`tests/test_math_verification.py`).

## R2. Normalization and Gram penalty (verified)
With each ‖A_k‖_F = √2, diag G = 2, so ‖G − cI‖² = Σ_{i≠j} G_ij² + K(2 − c)². The target c changes only a constant,
so the gradients are identical for every c. The original pilot explanation ("target I penalized the true basis")
therefore cannot hold for this implementation, and it has been removed. **Check:** T3.

## R3. Proposition 1 (exact closure integrates): correct, standard
Bilinearity and antisymmetry make a commutator-closed linear span a Lie subalgebra; the Jacobi identity is
automatic for matrix commutators. The Lie subgroup–subalgebra correspondence (Hall 2015, Ch. 5) gives a unique
connected Lie subgroup H generated by exp 𝔞.

H is in general only immersed. Counterexample to closedness: in so(4), a line spanned by E₀₁ + αE₂₃ with α irrational
is closed (dim 1), but exp of it is dense in a 2-torus.

This is a standard fact, not a contribution. The paper labels it as such.

## R4. Lemma 1 (loss controls uniform escape): verified, general form
**Hypothesis:** G invertible. Define δ(𝔞) = sup_{X,Y∈𝔞∖0} ‖N[X, Y]‖_F / (‖X‖_F ‖Y‖_F).

**Statement:** δ ≤ K √L(A; 0) / λ_min(G).

**Derivation.**
1. Write X = Σ x_i A_i and Y = Σ y_j A_j, and let r_ij = N[A_i, A_j], so N[X, Y] = Σ x_i y_j r_ij.
2. By the triangle inequality and then Cauchy–Schwarz in R^{K²},
   ‖N[X, Y]‖ ≤ (Σ x_i² y_j²)^{1/2} (Σ ‖r_ij‖²)^{1/2} = ‖x‖ ‖y‖ K √L.
3. Since ‖X‖² = xᵀGx ≥ λ_min ‖x‖², we have ‖x‖ ≤ ‖X‖ / √λ_min, and likewise for y.

**Counterexample search:** none. Equality is approached when all r_ij are aligned and x, y are aligned with the
extremal eigenvector.

**Check:** T4 compares the bound with δ computed by multi-start alternating maximization (a lower estimate of the
sup, so the check is conservative).

## R5. Proposition 2 (BCH escape): re-derived line by line; correct
**Hypotheses:** X, Y ∈ 𝔞 and ‖X‖_F, ‖Y‖_F ≤ r < (ln 2)/4.

**Statement.** dist(log(e^X e^Y), 𝔞) ≤ (δ/4)[−ln(2 − e^{4r}) − 4r] = δφ(r), and
dist ≤ ½δr² + C(r₀)δr³ for r ≤ r₀, with C(r₀) = (φ(r₀) − 4r₀²)/r₀³.

**Derivation.**
1. *Dynkin's formula.* log(e^X e^Y) = Σ_{m≥1} ((−1)^{m−1}/m) Σ [w] / (|w| Π r_i! s_i!).
   * The inner sum runs over words w = X^{r_1}Y^{s_1}⋯X^{r_m}Y^{s_m} with r_i + s_i ≥ 1.
   * [w] is the right-nested commutator, and |w| = Σ(r_i + s_i).
   * Coefficient magnitude: 1/(m |w| Π r_i! s_i!). (Standard; Bonfiglioli & Fulci 2012.)
2. *Norm of a nested commutator.* With the submultiplicative Frobenius norm, ‖[P, Q]‖ ≤ 2‖P‖‖Q‖. A length-n nested
   commutator has n − 1 brackets, so ‖[w]‖ ≤ 2^{n−1} r^n.
3. *Escape recursion.* Let e_n bound ‖N[w]‖ for |w| = n.
   * Base cases: e_1 = 0, since the letters lie in 𝔞, and e_2 ≤ δr² by the definition of δ.
   * Write [w] = [W, Z] with W ∈ {X, Y} and Z of length n − 1. By linearity of N,
     N[W, Z] = N[W, P₀Z] + N[W, NZ].
   * First term: W and P₀Z both lie in 𝔞, so ‖N[W, P₀Z]‖ ≤ δ‖W‖‖P₀Z‖ ≤ δr‖Z‖ ≤ δ 2^{n−2} r^n.
     This uses ‖P₀Z‖ ≤ ‖Z‖, true because P₀ is an orthogonal projection.
   * Second term: ‖N[W, NZ]‖ ≤ ‖[W, NZ]‖ ≤ 2r e_{n−1}.
   * Induction: e_n ≤ δ2^{n−2}r^n + 2r(n−2)2^{n−3}δr^{n−1} = (n−1)2^{n−2}δr^n. ✓
4. *Termwise bound.* (n−1)2^{n−2}r^n / n ≤ ¼(2r)^n. Summing (2r)^{r+s}/(r! s!) over (r, s) ≠ (0, 0) gives
   e^{4r} − 1, so the full sum is Σ_m (1/m)(e^{4r} − 1)^m = −ln(2 − e^{4r}), finite iff r < (ln 2)/4.
5. *Remove the zero-escape terms.* The length-1 words occur only for m = 1, (r, s) ∈ {(1, 0), (0, 1)}, and
   contribute 2r each. They have zero escape, so subtracting 4r gives the first bound.
6. *Sharpen the quadratic term.* The length-2 words sum exactly to ½[X, Y], whose escape is at most ½δr². Their
   contribution to the crude bound is (δ/4)·16r² = 4δr². Breakdown of the 16r²:
   * m = 1: (2, 0), (1, 1), (0, 2) give 2r² + 4r² + 2r² = 8r²;
   * m = 2: four ordered tuples, 4r² each, times ½, give 8r².

   Replacing that contribution gives the second bound.
7. *Monotonicity of C(r₀).* −ln(1 − x) with x = e^u − 1 has non-negative Taylor coefficients in u, so φ(r) − 4r²
   has non-negative coefficients from r³ on, and (φ − 4r²)/r³ is increasing.
8. *Equality with the principal logarithm.* On the ball r < (ln 2)/4 the series converges absolutely, and
   ‖e^X e^Y − I‖ ≤ e^{2r} − 1 < 1, so the principal log is analytic there. Both sides agree near 0 (BCH theorem), so
   they agree on the connected ball.

**Behaviour as the defect vanishes:** both bounds are linear in δ and vanish at δ = 0, consistent with R3.

**Domain caveat:** the radius corresponds to rotations of at most ≈ 0.12 rad. Typical inferred actions in the
experiments are larger, so the bound is a local statement only, and the paper says so.

**Checks:** T5 (400 random pairs, four settings).

**Verdict:** correct. I kept the explicit-constant version because every step above is elementary. A reviewer who
prefers less can use only the first bound.

## R7. Proposition 4 (closed subalgebras in the benchmarks): re-derived; conjugation group made explicit
**Background facts** (standard; the paper does not claim them as new):
(i) a subalgebra of so(d) carries the ad-invariant negative-definite form tr(XY), hence is compact and reductive;
(ii) so(4) = su(2)_L ⊕ su(2)_R, two commuting ideals that are Frobenius-orthogonal;
(iii) every automorphism of su(2) is inner;
(iv) maximal abelian subalgebras of a compact Lie algebra are conjugate (maximal-torus theorem).

**(a) T², K = 2, in so(5).** A 2-dim reductive algebra is abelian, since a semisimple part would need dimension
≥ 3. With rank so(5) = 2 it is maximal abelian, so it is conjugate to the true 𝔱² under SO(5) by (iv). ✓

**(b) SO(3), K = 3, in so(4).**
* A 3-dim reductive 𝔥 is not abelian, because rank so(4) = 2. It cannot be 𝔲(1) ⊕ (2-dim), because no 2-dim compact
  algebra is non-abelian. So 𝔥 ≅ su(2).
* Each projection π_L, π_R restricted to 𝔥 has an ideal as its kernel, and 𝔥 is simple, so each is 0 or injective.
  * If one projection is 0, 𝔥 equals the other factor.
  * If neither is 0, 𝔥 = {(X, φX)} with φ an automorphism, which is inner by (iii). Conjugating by an element of
    SU(2) × SU(2), which maps onto SO(4), turns 𝔥 into the diagonal.

  The diagonal is the stabilizer algebra of a unit vector, i.e. so(3) acting on R³ ⊕ R. ✓

**Conjugacy classes depend on the group** (made explicit in the final paper):
* **Under SO(4)** there are three classes: the diagonal (true), su(2)_L and su(2)_R. su(2)_L and su(2)_R are ideals,
  so they are fixed by every SO(4) conjugation.
* **Under O(4)** there are two: a reflection exchanges L and R.

"Two incorrect chiral classes" is correct under SO(4) and wrong under O(4). The Procrustes alignment used in the
experiments allows reflections, so it measures O(4) classes. The paper now says "two chiral factors (one class up
to reflection)".

**Abstract isomorphism vs. conjugacy:** all three classes are isomorphic to su(2) as Lie algebras. They differ as
*representations* on R⁴ (3 ⊕ 1 vs. the 2-dim complex representation viewed as real). Closure constrains only the
abstract bracket, so it cannot tell them apart.

**Independent invariants.**
* Pfaffian Pf(X) = x₀₁x₂₃ − x₀₂x₁₃ + x₀₃x₁₂ on √2-normalized elements: 0 (diagonal, rank-2 rotations), +½ (L),
  −½ (R). It is SO(4)-invariant and flips sign under reflections.
* Participation ratio: 2 vs. 4. It is O(4)-invariant.
* Chirality χ = e_L − e_R (Frobenius energy in each ideal): 0 vs. ±1.

**Checks:**
* T6, T8 (Pfaffian, chirality, SO(4) vs. reflection).
* The classification-free closure-flow search: 200/200 random starts converge to closed spans with χ ∈ {−1, 0, 1}
  to within 1.5 × 10⁻⁶, giving 192 diagonal, 5 L and 3 R (`results/review/closure_flow.json`).

**(c) K = 4.**
* A 4-dim reductive subalgebra of so(4) has semisimple part of dimension 3 (a single su(2); rank ≤ 2 excludes an
  abelian 4-dim algebra), so it is su(2) ⊕ 𝔲(1) with the 𝔲(1) central.
* The diagonal so(3) has trivial centralizer in so(4): its representation on so(4) ≅ Λ²R⁴ ≅ 3 ⊕ 3 contains no
  trivial summand.
* So the su(2) must be a factor, and such a span never contains the diagonal. ✓

**Check:** T6 (centralizer rank 6; random fourth generators never close; su(2)_L ⊕ 𝔲(1)_R closes).

## R8. NEW Proposition 5: endpoint ambiguity and zero-loss chiral solutions (the mechanism)
**Setting.** The SO(3) benchmark latent z ∈ R⁴, where g ∈ SO(3) acts on z₁:₃ and fixes z₄. Use the ground-truth state
map as the encoder (E = h⁻¹, D = h). An *endpoint rule* is a map q(z, z') ↦ coefficients, as in BracketNet, where
the action is inferred from the two codes only.

**(a) Chiral solutions are exact.** Let 𝔞 = su(2)_L (or su(2)_R). Left multiplication by unit quaternions acts
simply transitively on every sphere of R⁴ ≅ ℍ, and true transitions preserve ‖z‖. Hence:
* For every pair with ‖z‖ = ‖z'‖ > 0 there is a unique u = z'z⁻¹ ∈ SU(2) with L_u z = z'.
* q(z, z') = log u is continuous wherever u ≠ −1.
* L_{u₀₂} = L_{u₁₂} L_{u₀₁} exactly.

So transport and composition are exact on every triple whose coefficients lie in the coefficient domain. The
closure loss is 0, the Gram penalty is 0 (orthogonal basis), and Cov(E(x)) = Cov(z) = I. All loss terms vanish
apart from the coefficient bound: 8.6 % of the inferred edge-coefficient vectors (one- and two-step edges)
have a component above 0.65 and are clipped; for the true diagonal coefficients under the minimal-rotation rule the
fraction is 2.7 %.

**(b) The true diagonal algebra cannot be exact.** For any ε > 0, there is no continuous endpoint rule with values
in the diagonal group SO(3) that transports and composes exactly on all triples in a sphere S = {‖z₁:₃‖ = ρ, z₄ = c}
with pairwise distances < ε.

*Proof.*
1. Exact composition on small triangles gives R(z, z) = I and makes products of R along ε-chains independent of the
   chain. Two chains that are homotopic through ε-chains are related by a sequence of small-triangle moves.
2. S ≅ S² is simply connected, so fixing e ∈ S, s(z) = (product along any chain from e to z) is a well-defined
   continuous map with s(z)e = z. That is a section of SO(3) → S², g ↦ ge.
3. Then v(z) = s(z)f, with f ⊥ e a fixed unit vector, is a continuous nowhere-zero tangent field on S², which
   contradicts the hairy-ball theorem. ∎

*Quantitative evidence (not a bound):* the minimal-rotation endpoint rule transports exactly but has composition
residual 3.2 × 10⁻³ on the actual data (test T7). Its small-triangle defect is a rotation about the start point
(holonomy).

**(c) Action identity is not recoverable even for the correct algebra.** g and g·exp(t·ẑ) have identical endpoints
(T7, `test_T7_stabilizer_component_is_invisible`). So for any estimator,
E‖ρ(q(z, gz)) − g‖² ≥ E[Var(g | z, gz)] > 0, because the conditional law of g is non-degenerate along the stabilizer
(MMSE lower bound).

This explains why correct-closed SO(3) runs keep an action disagreement of 0.36–0.43, while T², whose generic orbits
have trivial stabilizers, reaches 0.05–0.13.

**Corollary (embedding agreement without algebraic correctness).** Two models with identical embeddings (both E = h⁻¹,
so CKA = 1 and zero Procrustes residual with the truth and with each other), both with su(2)_L generators and the
chiral endpoint rule, have the following properties:
* zero closure, transport and composition loss (apart from coefficient clipping);
* cross-model algebra distance 0;
* ground-truth algebra distance ½;
* inferred actions unrelated to the true rotations.

All four properties are established by (a), Prop. 4 and T6 (distance ½).

**What this does and does not show.** It shows that at the ground-truth embedding the objective cannot prefer the
true algebra and strictly favours a chiral one on the composition term. It does *not* determine which solution
gradient descent reaches from a given initialization; that is studied empirically (trace, oracle intervention).

## R9. The implication chain, restated with hypotheses
1. Closure ⇒ correct conjugacy class: **true for T²** (R7a), **false for SO(3)** (R7b; chiral).
2. Correct class ⇒ recovery after latent alignment: **requires** that the encoder be close to an isometry of the
   true state space, i.e. orthogonal Procrustes is an adequate alignment. Not implied by closure; violated by the
   seed-level T² failures.
3. Recovery ⇒ correct action inference: **false for SO(3)** whatever the method (R8c: stabilizer ambiguity); true
   for generic T² points.
4. Cross-seed agreement ⇒ correctness: **false** (R8 corollary; one observed chiral–chiral pair at distance 0).

## R10. What is and is not new
The Lie-theoretic facts (R3, R7 background, the hairy-ball theorem, quaternion transitivity, Dynkin's formula) are
standard. The contributions are:
* their combination into statements about this learning objective (R1, R4, R5 constants, R8);
* the identification of endpoint ambiguity as the mechanism that makes the closure-regularized objective favour a
  wrong closed algebra.

I am not aware of prior work stating R8 for transition-based symmetry learners, but my literature check was limited
(see NOVELTY_COMPARISON.md).
